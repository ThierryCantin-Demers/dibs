Run commands on shared machines under a lock, so no one spoils a measurement.

Recipes
  dibs <verb> <repo>[@<ref>] <recipe>  build, test or bench; @local: your tree
  dibs list <repo>                     a repo's recipes and the values they take
  dibs runs [label]                    what was measured, and what compares
  dibs measurement <job|batch>         a run as one measurement, in JSON
  dibs with <repo> <service> -- <cmd>  a command against the repo's servers
  dibs shell <repo> --reason <why> -- <cmd>    a one-off in a prepared tree
  dibs raw --reason <why> -- <cmd>     a one-off with nothing prepared
  dibs gaps                            what fit no recipe, what got in the way
Calls
  dibs run [--bench] <cmd>             shared, or alone on the machine
  dibs --peek <cmd>                    a look that takes no lock
  dibs --sync <a> <b>                  rsync, ':' marking the machine's side
  dibs --hold <cmd>                    a command here under the machine's lock
Batches
  dibs batch <file|->                  one call per line, one summary at the end
  dibs batch --detach <file|->         driven on the machine, outliving this one
  dibs batch --follow <id>             wait on a detached or paused batch
Machines
  dibs status, dibs --watch            who holds each machine, and the queue
  dibs --machines, dibs machines       the inventory, and each machine's state
  dibs --check <host>                  install the runner, say what is there
  dibs --pick, dibs --which            where a call would go
  dibs --forget <machine>              drop a machine from your inventory
  dibs --measure <machine> on|off      whether a benchmark may run there
  dibs --close, dibs --open            close a machine you own, or open it
Jobs
  dibs out [job], dibs fetch <job>     what a job wrote, and the files it kept
  dibs --follow <job>                  wait on a job whose call checked in
  dibs --kill <pid|batch-id>           stop a job, or a whole batch
  dibs --release, dibs --gc --dry-run  a dead holder's lock; what fills scratch
  dibs --log [n]                       what ran, and how it ended
  dibs --friction '<line>'             record what got in the way
Setup
  dibs --update                        reinstall dibs, its recipes, its plugin
  dibs completions <fish|zsh>          shell completions
  dibs hook ssh, dibs hook urgent      Claude Code hooks
Flags  --on <machine>  --device <card>  --label <name>  --wait <s>  --max <s>
       --low-priority  --urgent '<why>'  --check-in <time>  --dry-run

dibs <command> --help   that command, and every flag it takes
dibs --help --all       every command and flag, and what each does
